# ☕ Project Context & Coding Rules

## 📌 Project Overview
This project is an **Online Menu and Ordering System** for a cafe. It features a customer-facing digital menu, an admin order management dashboard, a backend database.
---

## 🏗️ System Architecture & File Structure
* **`index.html`**: Customer-facing online menu interface for browsing items and submitting orders.
* **`submit.php`**: Backend endpoint processing order submissions from `index.html` and inserting them into the database.
* **`orders.php`**: Admin panel for viewing live incoming orders, managing fulfillment status, and handling shop workflows.
* **MySQL Database**: Central database storing customer orders, item details, status updates, and timestamps.
